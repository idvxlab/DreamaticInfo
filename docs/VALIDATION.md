## 当前范围限制

- 本地单用户部署，没有公网多用户认证/配额。
- PDF 扫描件需 OCR；旧 `.xls` / `.doc` 需转换；远程二进制文档需先下载再上传。
- 自动检查会校验结构、引用、引文、组件与事实标记，不会证明任意生成 JavaScript 的所有数据绑定都正确。
